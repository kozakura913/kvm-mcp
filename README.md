# KVM-MCP
UVCデバイスとCH9329でLLMにKVMを使わせるためのrust製MCPサーバー  
CH340とCH9329が連結したボードとMS2109キャプチャデバイスをRaspberryPi 1 A+に接続して、MCPサーバーの実装をLLM(Qwen3.8FlashNext)に丸投げして作成したプロジェクトです  
LLMの作業について権利がどうこう言うつもりは無いので同梱してあるボードとかの資料以外は好きにしてください  
使い方はserver/README.mdに書いてますが、LLM丸投げプロジェクトなので品質は悪いです  
作業時のメモもそのまま残してあるので典型的な症状の参考にでもなればいいと思います

## JPEGモードについて
初期実装のJPEGモードは最終的に廃止しました  
私の手元にあるUVCデバイスはJPEGモードを連打するとUSBからは見えるがHDMI入力を拾わない状態になるらしく、YUYVでは発生しないことからPi側でエンコードする仕様にしました
